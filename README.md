# AGSE-AdventureGameStudio-Audio-Extractor
A simple C# Command Line Tool for extracting audio from  AdventureGameStudio Engine Games.

### Compile:
Download the Source Code and Run **Build.bat**

Note: You must need .net 8.0 SDK, you can get it from [Here](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)

### Usage:
```
AGSE E <container> [folder]          Extract streams
  AGSE R <container> [folder] [/pad]   Repack into <container>_new
```
